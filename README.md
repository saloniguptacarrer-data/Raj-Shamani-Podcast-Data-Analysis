# 🎙️ Raj Shamani Podcast Data Dashboard (Google Sheets)

An interactive and visual data analysis dashboard built using **Google Sheets** to analyze performance metrics, video reach, and genre breakdown of podcasts hosted by Raj Shamani.

---

## 📌 Project Overview & KPI Highlights
* **Total Videos Analyzed:** 10
* **Total Views:** 30,935,238
* **Total Likes:** 1,019,400
* **Highest Engagement Rate:** 19.22%

---

## 📊 Key Visualizations & Features

1. **KPI Metric Cards:** Key high-level performance indicators summarizing reach and engagement across videos.
2. **Video Views Comparison (Bar Chart):** Ranks podcast episodes based on individual viewership (e.g., H.E. Emmanuel Macron, Bill Gates, Jayant Madhura).
3. **Content Category Distribution (Donut Chart):** Breaks down the channel's focus areas, highlighting **Politics & Geopolitics (29.4%)**, **Philanthropy (18.1%)**, **Finance (13.3%)**, and **Education (11.6%)**.
